## 5. Mesin Audio C++ (Oboe)

- [ ] 5.1 Buat `AudioEngine.cpp` / `AudioEngine.h` dengan class `AudioEngine` yang membuka Oboe stream tanpa menetapkan sample rate tetap (menggunakan `PerformanceMode::LowLatency` dan `SharingMode::Exclusive`), lalu membaca sample rate native stream untuk target resampling. Di Android 8.0 (API 26) otomatis menggunakan OpenSL ES — verifikasi: `./gradlew assembleDebug` berhasil compile C++ tanpa warning.
- [ ] 5.2 Implementasikan Voice Pool: struct `Voice` (pointer ke PCM asli di memori C++, PCM yang di-resample, posisi playback, aktif/tidak, gain) sebagai array statis 32 elemen yang dialokasikan di konstruktor; audio callback aman real-time tanpa `malloc`/`new`, tanpa mutex, dan tanpa JNI — verifikasi: inspeksi kode bahwa callback bebas alokasi dinamis dan locking.
- [ ] 5.3 Implementasikan resampling PCM di sisi C++: saat stream dibuka atau dibuka ulang (reconnect), buat salinan PCM yang di-resample ke sample rate native stream dari PCM asli menggunakan interpolasi linier; simpan PCM asli agar bisa di-resample ulang jika rate berubah dan pitch tetap benar — verifikasi manual: suara WAV dengan sample rate berbeda diputar dengan pitch benar di HP atau tablet fisik ARM.
- [ ] 5.4 Implementasikan Oboe audio callback (`onAudioReady`): (1) baca event sentuhan dari SPSC ring buffer lock-free, (2) kalikan tiap voice aktif dengan gain zona (0.0–2.0), (3) mix semua Voice aktif ke output buffer, (4) terapkan master limiter (soft-clip) untuk mencegah hard clipping — verifikasi: kompilasi bersih; banyak ketukan simultan dengan gain tinggi tidak menghasilkan distorsi clipping keras.
- [ ] 5.5 Implementasikan SPSC ring buffer (ukuran tetap, lock-free) di C++ untuk jalur trigger dari thread UI ke audio callback; audio callback hanya membaca ring buffer dan memulai voice tanpa memanggil JNI atau lock — verifikasi: review kode bahwa tidak ada mutex atau alokasi di dalam audio callback.
- [ ] 5.6 Implementasikan Voice Stealing: mendukung hingga 32 suara simultan tanpa saling memotong; saat > 32 suara aktif, `findSlot()` mengambil alih slot tertua dengan micro-fade-out 1ms untuk mencegah pop — verifikasi manual: rolling sangat cepat di HP atau tablet fisik ARM tidak menimbulkan bunyi pop.
- [ ] 5.7 Implementasikan JNI bridge:
    - `loadSound(ByteBuffer pcmData, int frameCount, int sampleRate, int slotIndex)`: Kotlin menyerahkan buffer PCM; C++ menyalin data PCM ke memori miliknya sendiri selama pemanggilan, lalu Kotlin bebas melepas buffer
    - `triggerSound(int slotIndex, float gain)`: memasukkan event ke SPSC ring buffer
    - `unloadSound(int slotIndex)`: membebaskan memori PCM slot
    - `releaseAll()`: unload semua slot
    - Penanganan kegagalan: bila data PCM gagal dimuat, zona diperlakukan sebagai tanpa suara (unassigned), log error dicatat, tanpa crash
    - Verifikasi: pengujian memastikan tidak ada crash saat load/unload/trigger berulang
- [ ] 5.8 Implementasikan siklus hidup audio: `pauseStream()` saat `onStop()` yang menghentikan semua voice aktif agar tidak ada bunyi menggantung saat resume, `resumeStream()` saat `onStart()`, dan reconnect otomatis saat headphone dicolok/dicabut (dengan resampling ulang jika rate berubah) — verifikasi manual: colok/cabut headphone tidak membuat audio mati permanen.
